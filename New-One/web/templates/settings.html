How it works

Settings are stored in data/detection_settings.json and picked up automatically by the CCTV monitor pipeline.

Disabling a detection type stops new observations for that violation. Existing active observations are resolved after their grace period.

PPE item toggles control which equipment types are required. One violation is created per person, listing all missing items together.

Default values come from config.yaml until you save changes here.
